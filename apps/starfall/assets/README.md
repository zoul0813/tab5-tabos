# Starfall Assets

All Starfall visuals were created specifically for this TabOS demonstration and are
distributed under the application MIT license. The starfield, ships, projectiles,
particles, and explosions are generated by application rendering code. `font5x7.inc`
contains the original limited bitmap HUD glyph set.

No third-party or commercial-game artwork is included. Future external assets may be
added only when verified as CC0 or public domain, with provenance recorded here.
