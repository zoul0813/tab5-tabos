# Lua audio validation — 2026-09-12

## Implementation

`tabos.audio` exposes bounded nonblocking signed-16-bit little-endian PCM playback
through the existing SDK. Streams support open, write, flush, volume, status, and
close; module info reports backend capability fields. Writes preserve partial
progress and EAGAIN without hidden waits, callbacks, or resampling. Accepted bytes
are copied by the service before return. Userdata, runtime slot ownership, and
generation checks provide cleanup and protect reopened streams from stale handles.

Snake remains one Lua file. Its start/eat/lose/win melodies, 44100 Hz mono samples,
60 ms notes, triangle phase and attack/decay envelope match native Snake at
`809b65f:apps/snake/src/sound.c`. That source was found in Git history because
`apps/snake` is absent on this branch. Lua explicitly reproduces C truncation toward
zero. PCM is cached at startup; playback reuses a stream and flushes old effects.
Pause stops sound, M toggles mute, and audio unavailability does not stop gameplay.

Snake sound prelude and compares all four PCM strings byte-for-byte against an
independent reference. Replacement, pause-stop, and mute are also checked.

RV32 integration covers audio open/write/status/flush/close, retained-stream errors,
os.exit, Ctrl-C interruption, repeat launches, and forced teardown alongside live
graphics. The actual Snake script runs with sound startup, mute toggles and restart.
