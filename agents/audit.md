# TabOS audit

Audit date: 2026-09-06. Accuracy verification: 2026-09-06. All 44 original findings were checked against their implementation paths; qualifications and source references below reflect that verification. Only this tracked file was changed by the 2026-09-06 verification. Later repairs are recorded under resolved findings. The working tree was clean at its start; the original report’s statement about pre-existing power-document changes is no longer current.

Findings use P1 (high impact), P2 (normal defect), and P3 (maintenance). Each checkbox represents a tracked repair task. Static findings include the triggering path and suggested validation; hardware-dependent concerns are identified explicitly. Planned features are not counted as dead code or defects merely because they are unfinished.

39 open findings: 3 P1, 34 P2, 2 P3; 7 resolved findings (AUD-002, AUD-003, AUD-005, AUD-006, AUD-008, AUD-011, AUD-014). Original findings retain corrected scope where needed; AUD-045 and AUD-046 are additional findings. Findings below are ordered by severity, then stable ID. Fix host signal handling and application/release build integrity next.

## Scope and validation

Review followed target/build configuration and boot into runtime/process ownership, ELF loading and call gates, SDK/libc, filesystem/storage, console/terminal/graphics, input/pointer, device registry, audio/camera, clocks/power, networking, bundled applications, tooling, CI, and documentation. Reference scans checked internal unused surfaces against callers, build lists, tests, SDK exports, and external callback conventions. Bundled application integration and project-owned driver code were reviewed; upstream third-party libraries, generated artifacts, binary assets, and the entire ESP-IDF dependency tree were not independently audited.

Evidence is primarily static control-flow, ownership, error-path, and contract review. Each finding gives a trigger, source location/function, repair direction, and proposed regression validation. The full proposed regressions were not added or run; focused reproductions completed during accuracy verification are listed separately below. Hardware/concurrency findings require targeted Tab5 validation; this review did not exercise physical hardware, live network peers, or extracted release packages.

## Findings

- [x] **AUD-003 — P1: Process cleanup renders queued blits after freeing guest memory.** `loader/elf_application.c:2348` destroys execution before `elf_graphics_drain()` at line 2365. On host, `platform/host/sdl/executable.c:1356` frees guest RAM, but queued blits retain pointers into that RAM. An application that queues a bitmap then exits/faults without presenting can cause a host use-after-free during cleanup. Tab5 stack-backed queued pixels also outlive task destruction. Stop execution separately from releasing its memory, or discard queued drawing during teardown. Validate an RV32 child that queues a blit then exits/faults under ASan.

- [x] **AUD-005 — P1: Blocking guest waits block the host runtime that must produce their events.** `platform/host/sdl/executable.c:851` calls the generic wait gate synchronously on the interpreter/runtime thread. `loader/elf_application.c:1296-1406` then loops/polls until timeout. An infinite pointer wait cannot receive SDL pointer events because that same thread must pump SDL and dispatch pointer updates; even finite waits freeze input, cursor deadlines, and close-window handling. Blocking socket/resolve/TLS gates use the same synchronous pattern. Implement resumable host waits or worker-backed operations, and validate an RV32 pointer wait while injecting SDL input and requesting shutdown.

- [x] **AUD-006 — P1: Native teardown deletes a potentially running task without a quiescence handshake.** `platform/esp32p4/executable.c:241-247` calls `vTaskDeleteWithCaps()` then frees its context. Normal completion publishes `finished` and wakes runtime before the task reaches `vTaskSuspend()` (`:54-57`); forced termination can interrupt any call gate while it owns a service mutex. The pinned local IDF explicitly requires the task not to be running on another core (`.local/esp-idf/components/freertos/esp_additions/include/freertos/idf_additions.h:342-345`). `elf_cancel_wait()` does not establish that condition. Add a stopped acknowledgement/join protocol, including cancellation of blocked service calls, before reclaiming task memory or context. Validate native return and forced shutdown under concurrent service calls on both cores.

- [x] **AUD-008 — P1: Fully horizontally clipped fills become huge memory writes.** `graphics/raster.c:35-52` never rejects `clipped_right <= left`. For a 1280-wide framebuffer, `raster_fill(framebuffer, 1281, 0, 1, 1, color)` passes `(size_t)(1280 - 1281)` to `raster_fill_span()`; a rectangle entirely left of the screen has the same problem. The scalar fallback then writes beyond the framebuffer instead of doing nothing. Queued native-resolution SDK fill/pixel calls reach this fallback when the platform fill backend rejects/fails an operation. Successful SDL/Tab5 clipping normally masks the defect; the fallback itself must remain safe. Return on an empty intersection before computing pointers/span sizes. Add ASan coverage for wholly left/right/off-screen and zero-size rectangles.

- [x] **AUD-011 — P1: Copying a file onto itself destroys its contents.** `apps/coreutils/src/cp/main.c:13-20` opens the source, then opens the destination with `O_TRUNC` without checking identity. `cp file file` (including normalized aliases such as `./file`) truncates the source before the first read and reports success. Resolve/check source and destination identity before truncation; ensure the SDK exposes enough identity information for host hard-link aliases if supported. Validate identical paths and equivalent drive-relative paths without losing original bytes.

- [x] **AUD-014 — P1: Relative executable paths use global filesystem cwd instead of the caller's cwd.** `loader/elf_application.c:2071-2102` stores the exec path verbatim, and `elf_entry():2123` passes it to `loader_elf_load_file()`. Although `process/process.c` copies the parent's per-process working directory into the child, the loader opens against the separate global cwd in `fs/filesystem.c`. `elf_fs_chdir()` only updates the process-local cwd. Consequently `cd T:/apps; ./foo` loads `T:/foo` or fails, and current-drive absolute paths after switching to A: use the wrong drive. Normalize the executable path against the caller's cwd before creating/loading the child. Validate relative PATH entries, `./`, `../`, and current-drive `/bin/foo` with distinct files in both locations.

- [ ] **AUD-016 — P1: Sending on a closed host socket can terminate the whole simulator.** `platform/posix/socket.c:277` uses `send(..., 0)` and socket creation does not suppress SIGPIPE; repository search found no SIGPIPE handler, `MSG_NOSIGNAL`, or `SO_NOSIGPIPE`. A disconnected peer can kill host TabOS instead of returning an application error. Suppress the signal in the platform backend on each supported host. Validate repeated sends after peer disconnect in a subprocess and require normal error return with runtime still alive.

- [ ] **AUD-025 — P1: Application builds do not track headers or per-app build settings.** `sdk/make/application.mk:68` makes the ELF depend on C/assembly sources, linker script, and the shared makefile only. Public/private SDK header edits, application header edits, changes to the application's Makefile, and changed heap/stack/ABI/contact-limit flags can leave an old executable considered up to date. This defeats the pre-release requirement to rebuild bundled applications with ABI changes and can silently install incompatible binaries. Track header dependencies and configuration inputs; validate header-only, per-app Makefile, and resource-flag changes rebuild the ELF.

- [ ] **AUD-026 — P1: Published host packages cannot start the required shell on a clean machine.** `.github/workflows/build.yml` packages only the host executable, SDL, and a launcher. Host rootfs is compiled from the CI checkout's absolute path (`config/Filesystem.cmake:1`), there is no runtime override in the backend/launchers, and neither host job builds/packages `T:/bin/shell`. `kernel_runtime_start(true)` requires that file. Package a usable rootfs/application set and resolve writable roots at runtime relative to an explicit installation/user-data location. Validate the extracted artifact in a clean directory without the build checkout.

- [ ] **AUD-001 — P2: Boot display name aliases a reused device-info buffer.** `kernel/runtime.c:298` passes `registered_device.driver` to `kernel_boot_report_add()`, which retains the pointer (`kernel/boot_report.c:43`). Subsequent keyboard/RTC/Wi-Fi/audio lookups overwrite that same local struct before the report is printed, so the Display entry reports another device's driver (normally audio). The retained report also holds a pointer into an expired stack frame after startup returns. Give report entries owned storage or copy the display name into storage with report lifetime. Validate serial and framebuffer reports with distinct display and audio driver names.

- [x] **AUD-002 — P2: Zero-time generic waits never poll socket readiness.** `loader/elf_application.c:1366` returns when `now_ms >= deadline_ms` before calling `platform_network_socket_wait()`. With `timeout_ms == 0`, an already-readable/writable socket reports zero unless a non-socket source happened to report readiness first. This breaks ordinary nonblocking event loops. Poll all sources once before deciding the deadline expired. Validate socket-only and mixed waits with queued socket data and zero timeout through the real ELF gate (SDK and backend tests alone miss this).

- [ ] **AUD-004 — P2: Zero-height bitmap divides by zero before validation.** `loader/elf_application.c:1977` computes `SIZE_MAX / height` before checking `height == 0`. The native-mode SDK forwards zero dimensions (`sdk/lib/graphics.c:242`), so valid error handling reaches undefined behavior on Tab5; host interpreter rejects the dimensions earlier, hiding the target difference. Validate dimensions before arithmetic and add zero-width/zero-height native-gate coverage.

- [ ] **AUD-007 — P2: Graphics line/outline arithmetic overflows and does not bound off-screen work.** `sdk/lib/graphics.c:179-224` subtracts arbitrary signed 32-bit endpoints, doubles signed Bresenham error, and adds dimensions to signed origins without range checks. Extreme legal coordinates produce signed overflow; a long off-screen line still performs billions of per-pixel call gates despite the clipped drawing contract. Clip with widened arithmetic before rasterization, including rectangle edge calculations. Validate `INT32_MIN`/`INT32_MAX` endpoints and completely off-screen primitives with a bounded operation count.

- [ ] **AUD-009 — P2: Root-process panic stays invisible during fullscreen graphics.** `process/process.c:44-55` uses `console_write_panic()`, but `console/console.c:83-98` still obeys global `graphics_active`; terminal rendering is disabled and `present_console()` skips presentation. A PID 0 graphics fault/exit therefore leaves the last graphics frame instead of the required framebuffer panic. Panic must explicitly restore a visible diagnostic surface without unloading process 0. Validate root failure after graphics open and assert panic pixels/text reach the display.

- [ ] **AUD-010 — P2: Terminal resizing bypasses the console mutex and graphics suspension.** `kernel/runtime.c:552-572` calls `terminal_resize()` before acquiring the console lock in `console_rebind()`, then unconditionally presents. Native console writes/cursor updates can access terminal allocations concurrently with resize. `terminal_resize()` preserves `rendering_enabled`, so it does not itself re-enable fullscreen terminal drawing; the unconditional `display_present()` still bypasses graphics suspension and can present the retained logical framebuffer over the native graphics surface. Perform resize and rebind under the same console-owned lock and honor graphics suspension. Validate concurrent output/scale changes and a scale change while graphics owns the framebuffer.

- [ ] **AUD-012 — P2: Failed non-application POSIX directory opens permanently consume pool entries.** `sdk/lib/posix_filesystem.c:99-134` marks a slot allocated before the `#else` call to `tabos_fs_opendir()` and returns NULL on a negative handle without clearing it. Eight failed opens exhaust the compatibility pool in kernel/built-in or host-native components compiled without `TABOS_APPLICATION`. This is not the normal Tab5-native ELF application path: both Tab5 and interpreted RV32 SDK applications define `TABOS_APPLICATION`, and that branch already rolls back a negative `fs_list` result. That branch leaks only when the runtime/listing gate is absent. Roll back allocation on every failure; validate repeated missing-directory opens followed by a successful open in the non-application build and unavailable-gate behavior in the application build.

- [ ] **AUD-013 — P2: `wc` reports success after open/read failures.** `apps/coreutils/src/wc/main.c:73-100` continues on a failed `fopen()` but always returns zero. Its counting loop also treats an I/O error as EOF and never checks `ferror()` or close errors. `wc missing-file` therefore prints an error while shell sees success, and a storage read failure yields a misleading partial count. Accumulate failure status and check stream errors; validate absent files and injected read failures.

- [ ] **AUD-015 — P2: Portable network state is shared across native tasks without synchronization.** `net/network.c` stores `current`, `password`, `retry_timer`, and `retry_suppressed` as ordinary globals. Runtime `network_service_update()`/`network_service_next_deadline()` race native application connect/disconnect/status gates (`loader/elf_application.c:785-833`), and graphics overlay status copies. The atomic notification flag protects notification only, not these state mutations/copies; torn strings/status and inconsistent retry deadlines are possible. Serialize service ownership or protect state with a platform mutex while keeping blocking backend work outside it. Add concurrent status/connect/disconnect/deadline validation.

- [ ] **AUD-017 — P2: Host TLS context is retained after failed trust-store initialization.** `platform/posix/tls.c:283-291` assigns `tls_context` before checking `SSL_CTX_set_default_verify_paths()`. On failure it returns without freeing/resetting the context; subsequent calls skip initialization, including `SSL_CTX_set_verify(..., SSL_VERIFY_PEER, ...)`. Preserve fail-closed initialization by publishing only a fully configured context and clearing failed allocations. Validate repeated connect attempts with injected trust-store initialization failure. Review the later verify-result check as part of that test; this finding does not assert an experimentally demonstrated certificate bypass.

- [ ] **AUD-018 — P2: `fetch` double-closes its output stream when finalization fails.** `apps/netutils/src/fetch/main.c:155-168` calls `fclose(output)` inside a short-circuit condition but clears `output` only if the subsequent rename also succeeds. A rename failure, or a failing fclose, reaches the final `fclose(output)` again on an invalid stream. Close exactly once and clear the pointer regardless of close/rename status. Validate injected close and rename failures under a native memory checker.

- [ ] **AUD-019 — P2: `fetch` assumes the entire HTTP header arrives in the first TLS read.** `apps/netutils/src/fetch/main.c:133-138` searches one receive buffer for the header terminator and rejects otherwise. A valid small response split across network/TLS reads therefore fails nondeterministically. Accumulate bounded headers across reads and retain any body bytes after the terminator. Validate every split point through `\r\n\r\n` and a genuinely oversized header.

- [ ] **AUD-020 — P2: `fetch` replaces destination with HTTP error bodies or incomplete downloads.** The receive path in `apps/netutils/src/fetch/main.c:133-158` skips headers without parsing status or Content-Length, treats any clean TLS EOF as success, and renames the temporary file over the destination. Where rename replacement is supported (including the host backend), a 404/redirect body or a truncated advertised body is reported as a saved download. On Tab5 an existing destination instead triggers AUD-045 and can reach the double-close in AUD-018. Validate success status and supported body framing/length before committing the destination; reject unsupported transfer coding explicitly. Preserve an existing destination on HTTP failure or truncation.

- [ ] **AUD-021 — P2: Graphics overlays are drawn into a buffer Tab5 fullscreen presentation ignores.** `graphics/display.c:155-211` draws battery/Wi-Fi overlays into the logical framebuffer before `platform_graphics_present()`. In direct mode, `platform/esp32p4/display.c:335-349` swaps native scanout buffers and never composites/copies the logical framebuffer. Thus enabled overlays disappear during native fullscreen graphics, although host shows them. Composite overlays into the active native draw surface through the platform abstraction, preserving application pixels. Validate enabled/disabled overlays in direct Tab5 graphics and host pixel-equivalent output.

- [ ] **AUD-022 — P2: Held-key repeat keeps obsolete modifier/text state.** `input/input.c:89-106` captures modifiers/text only on the non-modifier key-down/text events. Modifier press/release while that key stays held never refreshes them; repeats at `:125-153` keep the old modifiers and character. Holding Shift+A and releasing Shift keeps repeating uppercase/Shift-down events. Host's Sym synthesis also omits the repeat flag in its Sym branch (`platform/host/sdl/input.c:152-160`), allowing backend autorepeat text through in addition to portable repeats. Update held state on modifier transitions and mark/ignore backend-generated repeats consistently. Validate modifier changes during held repeats on both backends.

- [ ] **AUD-023 — P2: RTC/battery operation failures and recovery do not promptly update registry state.** RTC gates (`loader/elf_application.c:745-770`) never notify device readiness after reads/writes. Battery gates call `hardware_devices_update()`, but that function refreshes RTC/battery only when the 60-second audit timer expires (`kernel/hardware_devices.c:243-244`). Failures and successful retries can therefore remain invisible to subscriptions for nearly a minute, contrary to documented live operation-driven fault/recovery reporting. Publish a dedicated health-change hint and refresh affected cached driver health promptly; retain periodic audit for otherwise unreported changes. Validate failure and recovery before the audit deadline.

- [ ] **AUD-024 — P2: Headless host advertises working audio but never advances streams.** `platform/host/sdl/audio.c:150-152` returns successful playback/capture capabilities before creating streams or any replacement consumer/producer. Playback buffers eventually fill and never drain; capture never becomes readable. Audio applications and waits in headless RV32 validation stall despite successful open. Supply deterministic headless audio progress, or report the backend unavailable rather than ready. Validate write/drain and capture/wait through a headless runtime.

- [ ] **AUD-027 — P2: macOS package omits its OpenSSL runtime dependencies.** Root CMake links `OpenSSL::SSL`/`OpenSSL::Crypto`, but macOS packaging copies and rewrites only SDL. Homebrew-linked OpenSSL dylib paths therefore remain machine-specific dependencies and fail on a clean Mac without those libraries. Read-only `otool -L build/macos-debug/tabos_host` confirms `/opt/homebrew/opt/openssl@3/lib/libssl.3.dylib` and `libcrypto.3.dylib` in the existing local executable; a release artifact still needs clean-machine validation. Bundle/relocate/sign the required OpenSSL dylibs (or intentionally use a suitable static distribution), and inspect/transitively validate all dynamic dependencies before publishing.

- [ ] **AUD-029 — P2: Directory-list overflow is replaced with stale errno, often returning truncated success.** `loader/elf_application.c:720-732` sets `result = -TABOS_ENOSPC` when the fixed listing buffer fills, then overwrites every negative result with `-*tabos_errno_location()`. That errno need not be ENOSPC and is commonly zero after successful opens. SDK `opendir()` can therefore silently expose only the first part of a large directory. Preserve locally generated errors and translate only filesystem-call failures. Validate a listing larger than 4096 bytes with errno initially zero and nonzero.

- [ ] **AUD-030 — P2: Short stdin reads discard the rest of a text event.** `loader/elf_application.c:469-473` pops a complete text event but returns only `min(strlen(event.text), count)` bytes, without retaining the suffix. SDL text input can contain several characters, so byte-at-a-time readers such as IRC lose pasted/batched text. Reuse a bounded pending-input buffer for text as well as arrow escape sequences. Validate reading a multi-character input event one byte at a time.

- [ ] **AUD-031 — P2: Console writes discard bytes following embedded NUL while reporting full success.** `loader/elf_application.c:525-538` splits byte-counted stdout/stderr writes into NUL-terminated strings. `write(1, "A\0B", 3)` reports three bytes written but drops B because terminal string processing stops at NUL. This contradicts documented binary-transparent, CP437 byte-stream output. Add a length-aware terminal/console write path with explicit control-byte behavior. Validate embedded NUL followed by visible text and NUL at chunk boundaries.

- [ ] **AUD-032 — P2: IRC parses TCP reads as complete protocol messages.** `apps/netutils/src/irc/main.c:171-202` feeds each receive chunk directly to PRIVMSG/NAMES/PING/registration parsing. Split lines are lost; coalesced lines can lose messages or produce a malformed PONG. Accumulate bounded CRLF-delimited messages and process every complete line. Validate fragmented PING/001/PRIVMSG and multiple messages in one read after AUD-002 is fixed.

- [ ] **AUD-033 — P2: IRC server handling overwrites the user's current edit buffer.** `apps/netutils/src/irc/main.c:189-202` uses `line` for PONG and automatic JOIN while `used` still describes the user's typed draft, then truncates/redraws that overwritten buffer. A PING or registration completion during typing corrupts the outgoing message. Keep protocol output and editable input in separate buffers. Validate a partial draft surviving asynchronous PING and welcome/JOIN.

- [ ] **AUD-034 — P2: High-score save deletes the last good file after any rename failure.** `apps/starfall/src/storage.c:61-66` unlinks the existing score unconditionally if temporary-file rename fails, then retries rename. A transient storage error can erase the good score and lose the new one as well. Do not assume replacement is supported on every backend: AUD-045 confirms that the current Tab5 FAT backend rejects an existing destination. Introduce an explicit replacement/recovery strategy that preserves the previous score on failure. Validate injected rename failures preserve at least the original score.

- [ ] **AUD-035 — P2: ANSI parameters are concatenated instead of parsed separately.** `graphics/terminal.c:terminal_write()` skips semicolons without saving/resetting the current parameter. `ESC[2;3H` becomes row 23, column 1; `ESC[31;40m` becomes unsupported color 3140. Cursor A/B/C/D also treat omitted parameters as zero instead of the default one. Parse a bounded parameter list with command-specific defaults and implement the advertised cursor/color sequences. Validate standard two-coordinate positioning, multiple SGR attributes, and parameterless cursor movements.

- [ ] **AUD-036 — P2: ANSI cursor movement can leave the retained terminal history range.** `graphics/terminal.c:ansi_command()` subtracts cursor-up against absolute zero rather than `first_line`, adds cursor-down without a visible/history bound, and restores saved positions even after their lines have been evicted. Subsequent writes address ring slots belonging to other history lines; large movements also make resize iterate through arbitrarily many nonexistent lines. Keep a consistent screen/history cursor model and clamp/validate movement and restore. Validate movement after scrollback eviction, oversized row parameters, and resize after such input.

- [ ] **AUD-037 — P2: Terminal resize loses reverse-video attributes.** `graphics/terminal.c:terminal_resize()` replays each cell's character and colors but never copies `cell->reverse`, and also drops the current reverse attribute. Resizing/scaling removes selection/highlight styling and changes subsequent output despite preserving other colors. Preserve per-cell and active rendition state during reflow; validate mixed normal/reverse cells before and after scale changes.

- [ ] **AUD-038 — P2: Out-of-range epoch conversion overflows before rejecting the date.** `time/wall_clock.c:wall_clock_epoch_to_datetime()` and `sdk/lib/clock.c:epoch_to_datetime()` narrow `era` to `int32_t` and multiply by 400 before checking the supported 1970–9999 year range. Large positive epochs cause signed overflow; host `platform_wall_clock_set()` accepts these values. Reject epochs above the supported maximum before civil-date arithmetic, or retain wide arithmetic until validation. Validate the last second of 9999, its successor, and `INT64_MAX` under UBSan in both implementations.

- [ ] **AUD-039 — P2: Host setup omits a required OpenSSL development dependency.** `tools/tabos_tools/environment.py:setup_host_tools()` checks/installs SDL and build tools but neither checks nor installs OpenSSL, although root CMake requires SSL and Crypto. On a clean host, successful `./tools/tabos setup` can still leave host configuration unable to find OpenSSL headers/libraries. Add platform-appropriate dependency detection/install guidance and validate setup followed by configuration in clean macOS/Linux environments.

- [ ] **AUD-040 — P2: Application build argument forwarding reparses user data as shell code.** `apps/build.sh` constructs a quoted command string from arguments without escaping their contents, then executes it with `eval`. Literal dollar substitutions, backticks, and embedded quotes in make variable values are expanded/executed instead of being passed unchanged. Preserve argument boundaries without re-evaluation. Validate arguments containing spaces, quotes, literal dollar signs, and command-substitution syntax using a harmless argument-recording make substitute.

- [ ] **AUD-041 — P2: Nested exec does not transfer or restore fullscreen graphics ownership.** `loader/elf_application.c:elf_exec()` permits launching a child while the parent has an active graphics context; `process/process.c:launch_child_descriptor()` transfers console/pointer ownership only. The global graphics suspension remains set, hiding a text child's output. A graphics child can instead close the shared backend and clear suspension while the parent still believes its graphics session is active. Define and implement suspension/restoration of graphics ownership across nested execution (or explicitly reject unsupported nesting). Validate graphics parent → text child and graphics parent → graphics child → parent, including failed child startup.

- [ ] **AUD-042 — P2: Partial Tab5 Wi-Fi initialization is not unwound.** `platform/esp32p4/runtime.c:wifi_driver_init()` creates a default station netif, initializes Wi-Fi, and registers handlers in stages but returns directly on any later failure. `platform_network_shutdown()` skips driver/handler cleanup when `wifi_initialized` is false and deletes the status mutex. A registered event handler can consequently survive with a deleted/NULL mutex; the netif is also never retained/destroyed on normal shutdown. Track initialization stages and unwind them in reverse order, quiescing the startup task/events before releasing shared state. Validate failures after each registration/start step and shutdown during startup on Tab5.

- [ ] **AUD-044 — P2: Architecture checks omit several current portable subsystems and applications.** `tests/check_boundaries.cmake` still lists nonexistent top-level `shell` but omits `console`, `process`, `time`, `pointer`, `camera`, and SDK implementation sources. `tests/check_application_api_boundary.cmake` covers only shell/tester/hello/coreutils, excluding netutils, games, and graphical apps. `check_naming.cmake` also omits audio/net/pointer/camera. CI can therefore pass when platform headers/private ABI or prohibited naming enter these maintained areas. Derive coverage from maintained source inventories or keep explicit lists complete; validate each previously omitted area with in-memory/isolated negative fixtures when implementing the fix.

- [ ] **AUD-045 — P2: Tab5 FAT rename cannot replace existing files, breaking repeated saves.** `platform/posix/storage.c:373-389` delegates directly to libc `rename()`. The pinned local ESP-IDF FAT adapter (`.local/esp-idf/components/fatfs/vfs/vfs_fat.c:869`, `vfs_fat_rename()`) calls `f_rename()` without replacement handling; its FAT/FAT32 branch (`.local/esp-idf/components/fatfs/src/ff.c:5240`) returns `FR_EXIST` for a distinct existing destination, mapped to `EEXIST`. The currently unused `network_config_save()` has the same latent mismatch; host POSIX rename masks it in tests. This finding is established statically from the local dependency implementation, not a physical-card reproduction.

- [ ] **AUD-046 — P2: Directory listing serialization splits legal host filenames into false entries.** `loader/elf_application.c:724-728` serializes each name as unescaped `F:<name>\n` or `D:<name>\n`; `sdk/lib/posix_filesystem.c:149-164` treats every newline as a record boundary. `fs/path.c:consume_path()` permits embedded newlines and the host POSIX backend supports them. A single regular file named `a\nF:b` is therefore exposed to SDK `readdir()` as two files, `a` and `b`, neither representing its actual name. If such names are intentionally unsupported, reject them consistently at the filesystem boundary and define how imported host entries are handled. An isolated probe of the current SDK parser confirmed the split; Tab5 FAT filename support is not assumed.

- **AUD-005 — Resolved 2026-09-07.** Host RV32 gates now retain the call site/registers while an operation is pending and publish a retry deadline instead of keeping the interpreter immediately runnable. - **AUD-006 — Resolved 2026-09-07.** Native task lifetime now resides in `platform/esp32p4/application_task.c`. All 97 private ABI entries use guards that track active gate depth and park on stop; an ABI-size assertion catches added entries without guards. `platform_riscv32_stop()` requests stop, suspends the task, and waits until `eTaskGetState()` confirms it is not running on either core. It deletes only after active gate depth reaches zero. If a gate is active, it issues nonblocking cancellation and resumes the task so the gate can consume its worker response and release service mutexes, then parks before returning to guest code. The loader calls this handshake before task, stack, service-resource, heap, or mapping reclamation. Native socket waits/accept/connect/transfers and ICMP receive waits use bounded cancellation polls; TLS uses nonblocking handshake/I/O retries. Worker callers consume replies and release their mutexes before gate exit. Cancellation does not suppress handle-close rollback, and new submissions from a stopping task are rejected. An already-entered lwIP resolver or the bounded ESP-TLS TCP-connect readiness call can delay cleanup; state is retained until those calls return, with no timeout-based unsafe deletion.

  Scope correction discovered during repair: the pinned ESP-IDF `prvTaskDeleteWithCaps()` implementation already suspends the target and checks `eTaskGetState()` before freeing its stack. The original return-before-self-suspend observation is therefore not independently proof of a stack-free race with this pinned helper. The confirmed defect is deleting a task while it still owns resources inside a call gate; that helper cannot release service mutexes or drain application-worker replies. Original finding text/order is preserved above as requested.

  Regression: an isolated build of the previous task implementation against `unit.native_task` failed at the deletion assertion that no service gate owns its mutex, even though the fake deletion helper models IDF's existing suspension handshake (`/tmp/tabos-aud006-before-fyrgaw7_/`).
